Rules for every tab

Don't touch row 1Row 1 holds the column names. Don't rename, delete or move them (Price Tiers is the one exception).
Row 2 is an exampleType over it with real data, or leave it exactly as it is and it is skipped.
One row per thingOne supplier, one item, one invoice per row.
Dates: 2026-10-16Year-month-day. Money as plain numbers: 12500, no ₱, no commas.
Empty tab = skippedLeave any tab you don't need blank. Nothing happens to it.
You see only your tabsThe workbook holds only the tabs your role can import. Clients appears for logistics businesses only.
Help tabs at the endHow to fill explains every column, Valid Values lists accepted words, Accounts lists account codes.

Which tabs you need

Just starting with the appSuppliers, Clients, Inventory. Add Price Tiers if customers pay different prices. This is enough to start selling and buying.
Moving over from existing booksAlso: Chart of Accounts (only if your books have their own codes), P&L History, Opening Balances, Open Receivables, Open Payables, Open Deposits & Advances.
Orders already placed with suppliersPurchase Orders.
New bills, expenses or equipmentBills, Expenses, Fixed Assets. Expenses and Fixed Assets post to the books straight away.

The tabs

The app imports the tabs in the workbook's own order, because later tabs refer to earlier ones (a bill names a supplier). Fill them in any order, but a name used on one tab must already be on the tab it comes from.

Importing

  1. Save as .xlsx. Keep every tab, even the empty ones.
  2. In the app: Ledger → Export All → Start from templates → Import all, then pick the file.
  3. Read the preview ("This workbook will import"). It shows the rows found on each tab and any problem, by row number. Nothing is saved yet.
  4. Fix and re-import if anything is flagged. Importing again is safe: existing suppliers and clients aren't duplicated.
  5. Press Import. The tabs go in, in order, and the result lists what was added on each.

Prefer Google Sheets? Keep the workbook there and link it under Settings → Setup workbook from Google Sheets.

Before you press Import

Quickest start: fill only Suppliers, Clients and Inventory, import, and add the rest later. Each tab can be imported on its own at any time.
